# Pitch do Projeto

## Romaneio de Pesagem de Bovinos

**Integrante:** Heloina Lorena Santana Marinho

### Problema
O registro manual das pesagens pode dificultar a organização e a consulta dos dados dos bovinos.

### Solução
Uma aplicação web em Flask que permite cadastrar, consultar, editar e excluir pesagens, além de mostrar o peso total registrado.

### Público
Produtores rurais e pessoas responsáveis pelo controle de pesagem dos animais.

### Tecnologias
Python, Flask, SQLite, HTML5, CSS3, Git e GitHub.

### Segurança
O sistema utiliza autenticação por sessão, senha armazenada com hash e proteção CSRF nos formulários.

### CRUD
O sistema possui operações de criação, leitura, atualização e exclusão pela interface web e uma API com GET, POST, PUT e DELETE.

### Próximos passos
Publicação da aplicação em ambiente de hospedagem, testes finais e apresentação do projeto.
