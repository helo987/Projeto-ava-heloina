# Projeto Software Agro – Romaneio de Pesagem de Bovinos

## Sobre o Projeto

O **Romaneio de Pesagem de Bovinos** e um sistema desenvolvido para auxiliar no cadastro de bovinos e no registro de suas pesagens.

O sistema busca solucionar dificuldades encontradas no controle manual das informacoes dos animais, como perda de dados, registros desorganizados e dificuldade para consultar os pesos dos bovinos.

## Objetivo

Desenvolver um sistema simples para cadastrar bovinos e registrar suas respectivas pesagens, facilitando a organizacao e a consulta dessas informacoes.
