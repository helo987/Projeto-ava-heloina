# 🐄 Romaneio de Pesagem de Bovinos

## 📌 Sobre o projeto

O projeto tem como objetivo desenvolver uma aplicação web para auxiliar no controle e organização da pesagem de bovinos.

No trabalho no campo, registrar e organizar os dados de peso dos animais manualmente pode dificultar o acompanhamento das informações. O sistema busca facilitar esse processo, permitindo cadastrar, visualizar, atualizar e excluir os registros dos bovinos.

## 🎯 Objetivo

Criar uma aplicação web simples para organizar os registros de pesagem dos bovinos e facilitar o acompanhamento das informações.

## 🌱 Problema do Agronegócio

A falta de organização dos registros de pesagem pode dificultar o controle dos animais e a consulta das informações. O sistema foi pensado para centralizar esses dados em um único local.

## ⚙️ Funcionalidades

* Cadastro de bovinos;

* Registro do peso;

* Visualização dos registros;

* Atualização dos dados;

* Exclusão dos registros;

* Cálculo do peso total;

* Organização das informações em uma aplicação web.
